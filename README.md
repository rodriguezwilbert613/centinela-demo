# centinela-demo

Repositorio de demostración de Centinela C++: cada pull request se revisa con el
checker `ucsm.ContainerInvalidation`, que detecta usos de iteradores, referencias y
punteros invalidados en contenedores de C++17. La rama `main` exige el estado
`centinela/invalidacion` para hacer merge.

Proyecto: https://github.com/jasrod12ucsm/checker
